# 🔍 fullstack-code-review — รีวิว Skill (ภาษาไทย)

> **ให้ AI สวมบท Senior Engineer ช่วยตรวจโค้ดทั้ง Frontend & Backend แบบจัดระดับความสำคัญ P0/P1/P2 พร้อมหลักฐานผลรันจริง**

## คำสั่งติดตั้งเฉพาะ Skill นี้

```bash
npx skills add https://github.com/pratchayawutthansrii/intern-dev-skills --skill fullstack-code-review
```

---

## ตัวนี้เหมาะกับงานอะไร / ใครควรใช้?

- **น้องฝึกงาน**: ใช้ให้ AI ช่วย **Self-Review โค้ดตัวเองก่อนส่งงานให้พี่เลี้ยง** เพื่อจับบั๊ก จับช่องโหว่ และแก้จุดพลาดล่วงหน้า
- **พี่เลี้ยง / Team Lead**: ใช้ตรวจ Branch หรือ PR/MR ของน้องในทีม (ทั้งฝั่ง Frontend, Backoffice และ API) ให้ได้รายงานชัดเจนและข้อความแจ้งฟีดแบ็กที่สุภาพ ตรงประเด็น

---

## ตัวนี้ช่วยอะไรบ้าง?

1. **ตรวจครบ 4 เสาหลักในรอบเดียว** — ตรวจทั้ง Logic/Edge Cases, Security (OWASP/RBAC), Performance/Maintainability และรันคำสั่งตรวจสอบจริง (`tsc`, `build`, `test`)
2. **จัดระดับความรุนแรงชัดเจน (P0 / P1 / P2)** — แยกให้เห็นชัดว่าเรื่องไหน **ต้องแก้ด่วนก่อน Merge (Blocker)** และเรื่องไหนเป็นข้อเสนอแนะเพิ่มเติม
3. **ชี้พิกัดไฟล์ + บรรทัด + แนวทางแก้แบบจับต้องได้** — ไม่คอมเมนต์ลอย ๆ แต่บอกเหตุผลว่าพังยังไงและควรแก้โค้ดตรงไหน
4. **ไม่มโนผลเทส** — บังคับให้รายงานผลรันจริงพร้อมเลข commit และสรุปฟันธงว่าพร้อม Merge หรือควรแก้ก่อน

## ตัวอย่างการใช้งานจริง

- *"ใช้ skill `fullstack-code-review` ช่วยตรวจโค้ดใน branch ของฉันเทียบกับ `main` พร้อมรัน typecheck, build, test ก่อนส่งให้พี่เลี้ยง"*
- *"ใช้ skill `fullstack-code-review` รีวิวโค้ด branch `Korawit` ของทั้ง Frontend และ Backoffice แล้วสรุปเป็นข้อความสำหรับแจ้งน้องว่าควรแก้ตรงไหนบ้าง"*

### ภาพเปรียบเทียบความต่าง (ก่อนใช้ vs หลังใช้)

| รีวิวแบบทั่วไป | รีวิวด้วย `fullstack-code-review` |
| --- | --- |
| บอกแค่ "โค้ดดูดีแล้วครับ" ทั้งที่ยังไม่ได้รัน build | รัน `tsc` + `build` + `test` จริง และรายงานจำนวนเทสที่ผ่าน/ตก |
| คอมเมนต์ปนกันไปหมด ไม่รู้เรื่องไหนด่วน | แยกชัดเจน 🔴 P0 Blocker / 🟠 P1 High / 🟡 P2 Improvement |
| ชี้ปัญหาแต่ไม่บอกว่าทำไมถึงเสี่ยง | ระบุไฟล์+บรรทัด+ความเสี่ยงจริง+ตัวอย่างวิธีแก้ที่นำไปใช้ได้ทันที |
