# 🎨 clean-editorial-ui — รีวิว Skill (ภาษาไทย)

> **ออกแบบ UI หน้าเว็บให้เรียบหรู สะอาด เป็นธรรมชาติ และกลมกลืนกับดีไซน์เดิมของเว็บ — ไม่ติดกลิ่น "UI ที่ AI เจนมา"**

## คำสั่งติดตั้งเฉพาะ Skill นี้

```bash
npx skills add https://github.com/pratchayawutthansrii/intern-dev-skills --skill clean-editorial-ui
```

## ตัวนี้เหมาะกับงานอะไร / ใครควรใช้?

- น้องฝึกงานสาย **Frontend / Full-Stack** ที่ทำหน้า Landing Page, Pricing Card, Callout Box, Hero, Form หรือ Backoffice ด้วย **React + Vite + TypeScript + Tailwind CSS**
- งานปรับแก้ UI ในโปรเจกต์ที่มี Design System อยู่แล้ว (เช่น เว็บไซต์บริษัท เว็บองค์กร หรือระบบหลังบ้าน) แล้วไม่อยากให้หน้าใหม่ดู "โดด" หรือ "รก" แตกต่างจากหน้าเดิม

## ตัวนี้ช่วยอะไรบ้าง?

1. **บังคับให้ AI อ่าน Design System ของเว็บก่อนแก้เสมอ** — ใช้สีขอบ มุมโค้ง เงา ปุ่ม และขนาดฟอนต์ชุดเดียวกับส่วนอื่นในเว็บ ไม่คิดสีใหม่มั่ว
2. **ตัดลูกเล่น AI-Slop ออกหมด** — ห้ามใส่การ์ดดำเรืองแสง, แสงเบลอ `blur-2xl`, ป้ายแคปซูลซ้อนกันหลายชั้น, ขอบหนา 2px หรือปุ่มไล่สีฉูดฉาดโดยไม่ได้ขอ
3. **จัดลำดับการอ่านให้ชัดเจน (Typography & Scannability)** — แยกย่อหน้ายาว ๆ ให้กลายเป็นคำนิยามสั้น + จุดเด่น 3 ข้ออ่านง่าย และคุมขนาดหัวข้อทั้งหน้าให้เท่ากัน
4. **คุมมาตรฐาน Accessibility & Contrast (WCAG AA/AAA)** — กันพลาดเรื่องตัวหนังสือสีทองอ่อนบนพื้นขาวที่อ่านยาก และเช็กขนาดปุ่มบนมือถือไม่ให้เล็กเกิน 44px
